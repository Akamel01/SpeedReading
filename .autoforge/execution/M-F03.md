# M-F03: pure activeMs in metrics.js + app.js call-site replacement

- Edits performed:
  - src/lib/metrics.js: Implemented and exported activeMs(events) per contract. Handles empty/1-element inputs and sums per-gap contributions with cap based on previous event's expectedMs.
  - src/app.js: Replaced inline active-time accumulation with an events array readEvents collected during chunk emissions; imported and used activeMs(readEvents) to compute elapsed time at session end.
- Tests updated:
  - test/metrics.test.js: Added unit tests for activeMs covering empty, single event, simple gap, large gap cap, and multiple gaps. Extended import to include activeMs.
- No other parts of the codebase were touched.

- Rationale:
  - Aligns with ADR-13 §8 (freeze) and contract for activeMs: returns 0 for empty and sums per-gap clamped by expectedMs*4+250.
  - Uses existing gating and fallback behavior in recordSession for elapsed time, preserving UX.

## Findings

1. **(Info)** ADR-12's sketch names `renderAnswering`/`renderAuthoring`; shipped names are `start`/`startAuthoring`. Contract comment (line 2) and `app.js` agree with the shipped names — no action.
2. **(Low)** The answering payload spreads the full question (line 156), so `answer`/`accepted` travel in memory to `app.js` and are persisted after save. Not an ADR-12 violation (no DOM exposure, no store write pre-save; the persisted quiz needs expected answers for scoring/authoring).
3. **(Low)** Harness check `answeringDomHasExpected` scans `textContent` for a fixed word list; a cloze sentence that itself contained "fox"/"four" would false-positive. Fixture is clean and the probe confirmed `textContent` directly — hardening optional if sentence sources become arbitrary.
4. **(Positive)** e2e walkthrough 25/25 and quiz unit suites green against the current tree.

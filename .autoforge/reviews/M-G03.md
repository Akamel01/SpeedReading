## Blockers (each needs a fix before approval)

**B1 — drill-master target lowered from 10 to 5 (contract violation).** `src/lib/achievements.js:145`.
Fix: `target = 10`. No test change required (fixture has 10 drills; verified). Update stale comment `test/achievements.test.js:15`.

**B2 — drill exclusion missing for speed stamps.** `achievements.js:67-72` (wpm/comprehension accumulation over all `S`), `:136-138` (wpm unlockAt filters). A span drill with `wpm:400, comprehensionPct:100` unlocks `wpm-300` (probe a2); ADR-24 `decisions.md:340` excludes drills from speed/comprehension achievements.
Fix: skip `String(s.drill) === 'span'` in the wpm/comprehension accumulation and in the wpm-300/450/600 filters.

**B3 — `first-record` is unconditionally unlocked.** `achievements.js:139-140`: `unlocked = true` for any input, including zero sessions (probe e); on empty input `unlockedAt` is `Infinity` (empty `Math.min`), leaking through `unlockedAt ?? null` at `:154`. Requirement: "Improve a WPM personal record (scored, ≥60%)" (ADR-24:328).
Fix: over drill-excluded sessions with `comprehensionPct ≥ 60` sorted by `startedAt`, unlock when a session's `wpm` strictly exceeds the max of all earlier scored sessions; `unlockedAt` = that session's `startedAt`; else locked/null.

**B4 — `sustained-improvement` predicate not implemented.** `achievements.js:141-142` only checks `S.length >= 3`. Requirement: "3 scored sessions in a row, wpm non-decreasing, comprehension ≥70% each" (ADR-24:329).
Fix: on chronologically sorted drill-excluded scored sessions, find the first 3-run with `wpm[i] ≤ wpm[i+1] ≤ wpm[i+2]` and `comprehensionPct ≥ 70` each; `unlockedAt` = 3rd session's `startedAt`.

**B5 — `comeback` can never unlock.** `achievements.js:74-87` builds `last7Dates` filtered to the last 7 days, then scans gaps ≥14 days over that same 7-day window (`:82-87`, used at `:131-132`) — mathematically impossible. Probe (f): 20-day gap → locked.
Fix: derive sorted distinct local day-keys from all sessions with numeric `startedAt`; unlock when consecutive days differ by ≥14 days; `unlockedAt` = `startedAt` of the earliest session on the later day.

**B6 — `unlockedAt` is not the earliest qualifying event.** `achievements.js:119-125, 130, 133-138, 143-145` return `Math.min(startedAt)` over *all* sessions (or `now` for streak-3/7/30/100 at `:126-129`). Probe (b): `sessions-10` reports the 1st session's time, not the 10th's; the 1st session did not qualify. ADR-24:303 / plan §M-G03 freeze "earliest qualifying event".
Fix: return the crossing event's timestamp — Nth session by `startedAt` for count thresholds; cumulative-sum crossing session for word thresholds; the session/quiz whose value crosses the pct/WPM threshold; for streak stamps the timestamp of the day the run reached target (compute local day keys locally; no streak.js import).

## Major

**M1 — 6 titles differ from the ADR-24 exact table.** `achievements.js:20-25` vs `decisions.md:322-327`: `comprehension-80` "Comprehension 80" (ADR "Eighty percent"), `comprehension-90` "Comprehension 90" (ADR "Ninety percent"), `perfect-quiz` "Perfect quiz" (ADR "Clean sweep"), `wpm-300` "WPM 300" (ADR "Three hundred"), `wpm-450` "WPM 450" (ADR "Four fifty"), `wpm-600` "WPM 600" (ADR "Six hundred").
Fix: copy titles verbatim from ADR-24.

**M2 — `Date.now()` fallback contradicts the injected-`today` freeze and the file's own header.** `achievements.js:48` vs `:1`; ADR §13 `decisions.md:452-454` freezes `evaluate(sessions, quizzes, { today, streakStats })`.
Fix: treat missing `today` as absent (`null`) and skip date-dependent computations, or drop the header claim — prefer injected-only per freeze.

**M3 — malformed-input contract partially broken.** `evaluate(null, null, null)` throws before the `try` because parameter destructuring does not default for `null` (`achievements.js:43`); `Infinity` leaks as a non-null `unlockedAt` on empty input (`:140, :142, :154`). Acceptance requires malformed no-throw.
Fix: `evaluate(sessions = [], quizzes = [], opts = {}) { const { today, streakStats } = opts ?? {}; … }` and `unlockedAt: Number.isFinite(unlockedAt) ? unlockedAt : null`.

**M4 — test coverage does not meet the ticket's acceptance list.** `test/achievements.test.js`: no malformed-input call (comment at `:42-43` claims it, but `runOnce` never passes bad input), no per-requirement boundary assertions (`first-record`, `sustained-improvement`, `comeback`, wpm gates), no drill-exclusion assertion, no hidden-flag assertion, no `unlockedAt` assertion.
Fix: add explicit assertions after B1–B6 fixes: empty input → all locked with finite/null `unlockedAt`; `evaluate(null,null,null)` no-throw; drill wpm 400/comp 100 → wpm-300 locked; 20-day gap → comeback unlocked with return-session timestamp; 3-run sustained boundary both ways; comeback/marathon `hidden === true`.

## Findings (ranked)

### B1 — BLOCKER: year-boundary acceptance test still missing (`test/streak.test.js:84`)
Plan §M-G02 acceptance requires "month/year boundary" and round-1 required change #3 named the year-boundary case explicitly. Only the month case (`:72-84`) exists; no Dec→Jan case. Behavior itself is correct (probe: 2/2), so this is coverage, not a defect — but the acceptance list is unmet.
Fix: after `:84` add
```js
test('year boundary', () => {
  const map = dayMap([{ startedAt: ts(2026, 12, 31), words: 1 }, { startedAt: ts(2027, 1, 1), words: 1 }]);
  const res = streakStats(map, '2027-01-01');
  assert.equal(res.current, 2); assert.equal(res.longest, 2);
  assert.equal(res.lastDay, '2027-01-01'); assert.equal(res.activeToday, true);
});
```
then re-run `node --test test/streak.test.js` + `node --check src/lib/streak.js`.

## Ranked findings

### Blocker
1. **B1 — `w-comprehend` counts drill-session quizzes** (`src/lib/challenges.js:106`). ADR-24:340 excludes drill sessions from `w-comprehend`; the drill recognition quiz is persisted with `score.pct` and linked via `session.quizId` (`app.js:300-316`), so a ≥70% recognition quiz completes the weekly challenge (probe: `current 1`, expected `0`) — 150 XP/week from drills. Fix: `const drillQuizIds = new Set(list.filter((s) => s && s.drill === 'span' && typeof s.quizId === 'string').map((s) => s.quizId));` and add `!drillQuizIds.has(q.id)` to the `goodQuizzes` filter; add tests: drill-linked quiz pct 80 → 0, normal quiz pct 80 → 1, boundary pct 70 counts / 69 does not.

### Major

The prior re-queue instruction required a rewritten report listing each §13 function with one-line evidence. Fix: rewrite to r2 (exports, catalog, drill semantics, `16/16` tests, no-throw probes); delete line 13.

## Blockers (fix before approval)

**B1 — drill recognition quiz unlocks `perfect-quiz` (and `first-quiz`).** `achievements.js:115` (`quizPcts` has no drill attribution), used at `:169-172`, `:198`, `:214`. The app writes quiz records for drills with `score.pct` from recognition (`src/app.js:300-312`) and links them via `session.quizId` (`:316`), so this is reachable in real history. ADR-24 `decisions.md:340` excludes drills from comprehension achievements; brief `03-achievements.md:19` "never drill recognition".
Fix: collect `drillQuizIds = new Set(sessions.filter(s => s.drill === 'span' && s.quizId != null).map(s => String(s.quizId)))`, drop those ids from `quizPcts` (affects `first-quiz` and `perfect-quiz`). Test: drill session + linked `score.pct:100` quiz → both locked.

**B2 — streak `unlockedAt` is the first session, not the crossing event.** `achievements.js:206-209`: `longestStreak >= N ? nthAt(byEnd, 1) : null`. Probe P5: 3 consecutive days → `unlockedAt` = day 1 (both locally computed and injected `streakStats`). Contract: `unlockedAt` = earliest qualifying event (plan `plan.md:98`, ADR-24 `decisions.md:303`, prior B6).
Fix: compute local day serials from sessions (the file already has `localLongestStreak`/`serialFromKey`; no `streak.js` import), track the day where the run reaches N, and return the earliest session `endedAt` on that day. Keep the injected `longest` for the unlock decision (max with local run) and fall back to `null` only when no local run of N is derivable. Test: 3 consecutive days with injected `{longest:3}` → `unlockedAt` = day-3 session.

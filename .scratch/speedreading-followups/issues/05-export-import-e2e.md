## Agent Brief

**Category:** enhancement
**Summary:** Cover the JSON backup round-trip in the browser: export, wipe, import with confirm, verify records; reject bad files without data loss.

**Current behavior:**
Export downloads the store snapshot and import replaces local data after a confirm dialog, with schema validation. Both paths work by code inspection and the import validator was probed in Node, but no automated browser test exercises them end to end.

**Desired behavior:**
An automated browser run seeds a text plus a session, exports the snapshot, clears storage, imports the file through the real UI (accepting the confirm dialog), and asserts texts, quizzes, sessions, and settings round-trip intact. A second run feeds a wrong-schema file, dismisses nothing destructive, and asserts a readable error with existing data untouched.

**Key interfaces:**
- The store's export shape (schema version plus the four record collections) and import validator (schema mismatch and invalid-field errors): contract under test, not implementation
- The existing export/import UI entry points and confirm dialog: exercised, not rebuilt
- The zero-dependency browser walkthrough harness: extend it or add a focused script beside it

**Acceptance criteria:**

- [x] Dialog test: dismissing confirm performs no import and loses nothing
- [x] `node --test` green; walkthrough report records the new steps

## Agent Brief

**Category:** enhancement
**Summary:** Extract the pause-excluded active-time computation behind WPM into a pure function with unit tests covering pauses, hidden tabs, and mid-session speed changes.

**Current behavior:**
Reading time accumulates inside the composition root by summing capped gaps between chunk emissions; pauses and hidden-tab time are mostly excluded by a per-gap cap (4x expected chunk delay + 250ms). The logic is correct by inspection but has no direct tests.

**Desired behavior:**
A pure function takes an ordered list of chunk emission events (timestamp plus expected chunk duration at emission time) and returns active milliseconds, applying the documented pause-exclusion cap per gap. The composition root collects the events and calls the function; session WPM derives from its result exactly as today for uninterrupted sessions.

**Key interfaces:**
- Chunk emission event shape the engine already emits (index, chunk with word list): the only input the function needs
- The pure per-chunk delay helper: reused for expected durations
- The session record's elapsed/WPM fields: unchanged semantics

**Acceptance criteria:**
- [ ] Unit tests: uninterrupted session equals sum of expected delays (± rounding)
- [ ] Unit tests: a 10-second pause contributes at most the documented cap, not the full gap
- [ ] Unit tests: mid-session WPM change uses each chunk's own expected duration
- [ ] Unit tests: single-chunk and empty event lists don't produce NaN/Infinity
- [ ] Browser walkthrough WPM for a fixed-speed session unchanged (within rounding)
- [ ] `node --test` green

**Out of scope:**
- Changing the cap values' product behavior (document, don't retune, unless a test proves drift)
- Moving any other composition-root logic
